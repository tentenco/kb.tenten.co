關於這份知識庫

短文件，長期累積。

從工作情境找到文章，先看懂概念與原因，再依步驟開始做。

怎麼使用

  • 從專案情境、業務領域或搜尋找到知識。
  • 每篇依序說明概念、影響、重點、例子、做法與檢查方式。
  • 需要開始執行或交接時，在文末展開工作內容，補上專案脈絡；也能下載 Markdown。
  • Agent 依現有權限執行，交付成品與證據；人類判斷取捨與驗收。

這一版的知識邊界

  • 目前是依 Tenten 官網、官方文件、XTERRA repo 快照與通用實務整理的 32 份建議基線。尚未取得 Erik 過去 20 年的私人筆記與完整案例，不能代表已全部收錄。
  • XTERRA 已唯讀參考指定 GitHub repo 的程式與文件；尚未驗證正式帳號、寄送流程或完整搬站資料。Repo 描述不等於正式環境已驗收。
  • FDE 指深入客戶流程的工程交付方式；實際範圍、驗收與維運責任依專案約定。
  • 專案草稿、展開狀態與閱讀位置暫存在此瀏覽器分頁，可清除並撤銷；主題偏好保存在此瀏覽器。資料不會傳送到外部服務，請勿填密碼或 token。

怎麼繼續累積

  • 每次專案遇到新問題，優先補到現有卡片，不另開長篇文件。
  • 記錄情境、原因、做法、證據與什麼情況不適用；客戶細節放在有權限的專案資料中。
  • 平台重大更新、流程出錯或案例推翻原判斷時，重新查核來源與日期。
  • 指派維護角色與審稿節奏仍由團隊確認；本庫不虛構負責人。
