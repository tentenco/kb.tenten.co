Magento → Shopify 搬站

以 XTERRA 美國站需求為例，保住資料、搜尋與交易。

從第一篇開始 →先看整體步驟 ↓
完成這段工作，你會得到

新舊資料與網址對照表、搬站演練結果，以及正式切換和回復計畫。

01先盤點與理解架構02保住搜尋與數據03切換與驗收
01

先盤點與理解架構

知道哪些資產要搬，以及新系統如何分工。

  1. Magento → Shopify：網站搬家 →

    保住商品、交易、搜尋與量測；搬站要有對照表、演練與回復條件。

    2 分鐘

  2. Headless 電商：串接與驗收邊界 →

    自訂前台、Shopify 結帳與外部工具是三段系統，需逐段接通。

    3 分鐘

  3. Shopify 開店：先接通營運 →

    先確認商品、訂單與市場規則，再做店面和 App。

    2 分鐘
02

保住搜尋與數據

確認舊入口與購物紀錄都能接續。

  1. Technical SEO 與 301 Redirect →

    讓搜尋引擎找到正確頁面，並保留改版前累積的搜尋資產。

    3 分鐘

  2. GA4 電商：事件與轉換率怎麼算 →

    讓商品瀏覽、加購、結帳與成交形成可對帳的漏斗。

    3 分鐘
03

切換與驗收

把每個缺口變成可決定的上線條件。

  1. 電商上線：標準交付與驗收 →

    每次開店都帶這份清單，逐項交付交易、搜尋、量測與營運證據。

    3 分鐘

  2. 網站上線：一次看完必要條件 →

    上線前一次確認 SEO、交易、追蹤、DNS 與回復方案。

    2 分鐘
開始前要準備什麼？
  • 舊站／新店網址與資料匯出
  • 搬遷範圍、切換窗口和決策人
