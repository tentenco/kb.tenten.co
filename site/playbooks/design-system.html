Design System 與品牌落地

把品牌做成可重用的元件、規則與資產，讓不同畫面維持一致。

先懂概念掌握重點開始做確認完成

先理解

這是什麼？

設計系統把常用的顏色、字級、元件和互動規則整理成共用標準，讓不同人製作的畫面仍像同一個品牌。

什麼時候用

頁面開始變多、多人協作，或每次都重做相似元件時。

為什麼重要

  • 共用規則減少同一問題被反覆設計與開發。
  • 完整元件狀態讓 Agent 能延伸頁面，同時維持品牌與可用性。

掌握概念

記住這 3 個重點

  1. 樣式規則與元件分工

    tokens 定義顏色、字級、間距與動態；元件定義使用情境、狀態和行為。

  2. 資產要有正確版本

    品牌資產需要版本、授權、正確格式與可使用範圍。

  3. 必須在真實頁面上成立

    設計規則需落到程式與真實內容；不要只有簡報。

名詞小抄 2 個名詞
Token
共用樣式值，例如主色、字級與間距。
元件 Component
可重複使用、包含狀態與行為的介面單位。

用情境理解

舉個例子

三個頁面的主要按鈕有三種藍色、尺寸與錯誤提示。

這時要掌握的是

用同一組規則和元件，修改時才能一起更新。

接著開始做

從這一步開始

從按鈕、表單和文字層級這三組最常用元素開始整理。

開始前，準備這些資料 2 項
  • 核准品牌方向、logo、字型與素材授權
  • 既有程式庫、頁面種類、內容與語言需求
  1. 盤點重複樣式，建立語意 tokens 與元件清單。
  2. 產出按鈕、表單、導覽及內容模組的互動與響應規則。
  3. 交付可用元件、範例頁及版本變更紀錄，讓 Agent 以同一來源延伸。

怎麼知道完成了？

  • ✓真實長短內容、窄螢幕與錯誤狀態可用。
  • ✓設計與程式的 tokens 一致，素材可合法使用。

需要決定的事

確認視覺方向與共用規則，再讓後續畫面依同一套標準製作。

容易忽略的事

  • 每一頁各自發明字級和按鈕。
  • 未確認授權就把素材交付客戶。
